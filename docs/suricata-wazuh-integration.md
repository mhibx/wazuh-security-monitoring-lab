# Suricata and Wazuh Integration

## Objective

Integrate Suricata with Wazuh so that network security events generated by Suricata can be collected, analyzed, and monitored through the Wazuh SIEM.

The integration extends the existing lab from endpoint monitoring into network security monitoring.

## Detection Pipeline

The planned telemetry flow is:

```text
Network Traffic
      ↓
  Suricata
      ↓
   eve.json
      ↓
   Wazuh
      ↓
Detection Rules
      ↓
 Wazuh Alert
```

## Suricata Event Log

Suricata generates structured JSON events in:

```text
/var/log/suricata/eve.json
```

The `eve.json` file contains network security telemetry such as:

- Network flows
- Source and destination addresses
- Source and destination ports
- Protocol information
- DNS activity
- Suricata alerts

## Wazuh Integration

Wazuh can monitor the Suricata event log and process the generated JSON events.

The integration will allow Suricata network telemetry to become part of the existing Wazuh monitoring pipeline.

## Planned Configuration

The Wazuh agent or manager configuration will be updated to monitor:

```text
/var/log/suricata/eve.json
```

The configuration will use JSON log collection so that Suricata event fields can be processed by Wazuh.

## Detection Objective

The initial integration will focus on validating that:

1. Suricata generates an event.
2. The event is written to `eve.json`.
3. Wazuh successfully reads the event.
4. The event appears in Wazuh.
5. A detection rule can generate a Wazuh alert.
6. The resulting alert can be investigated through the Wazuh dashboard.

## Validation

The integration will be considered successful when a Suricata-generated event can be observed inside Wazuh.

The validation process will be documented after the integration is configured and tested.

## Current Status

Suricata is installed and running successfully.

Suricata configuration has been validated.

Suricata is generating `eve.json` network telemetry.

Wazuh integration is the next stage of the lab.

## Security Value

This integration expands the lab's monitoring capability beyond endpoint telemetry.

The resulting environment can correlate:

- Windows endpoint activity
- Sysmon telemetry
- Authentication events
- PowerShell activity
- Network traffic
- Suricata security alerts

This provides a foundation for investigating security events from both endpoint and network perspectives.
